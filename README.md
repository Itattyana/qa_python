# Тесты BooksCollector (10 тестов)

- add_new_book: валидное имя, длинное (>40), пустое, дубликат
- set_book_genre: установка жанра
- get_book_genre: получение жанра
- get_books_with_specific_genre: фильтрация по жанру  
- get_books_for_children: книги без возрастного рейтинга
- favorites: добавление/удаление/получение списка
